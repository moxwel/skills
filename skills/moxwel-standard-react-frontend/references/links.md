# Official docs

Check the source when an API is in doubt, since versions move fast. For Next.js, prefer `node_modules/next/dist/docs/` when it exists, because it matches the installed version.

- MDN HTML elements: https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements
- MDN URI fragment: https://developer.mozilla.org/en-US/docs/Web/URI/Reference/Fragment
- Base UI: https://base-ui.com/llms.txt (handbook: styling, composition, forms)
- Tailwind v4: https://tailwindcss.com/docs (preflight, responsive design, spacing)
- Next.js App Router: https://nextjs.org/docs/app (authentication guide, data security, server actions, route handlers)
- React: https://react.dev/reference/react (`useActionState`, `useTransition`, `cache`)
- `node:sqlite`: https://nodejs.org/api/sqlite.html; `node:crypto`: https://nodejs.org/api/crypto.html; `node:test`: https://nodejs.org/api/test.html
- PostgreSQL `pg`: https://node-postgres.com; MongoDB driver: https://www.mongodb.com/docs/drivers/node/current/
- Material Design Icons: https://pictogrammers.com/library/mdi/
- JSDoc tags: https://jsdoc.app/
- OWASP cheat sheets (passwords, sessions, input validation, SQL/NoSQL injection, XSS, file upload, OS command injection): https://cheatsheetseries.owasp.org/
